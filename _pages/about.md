<section class="about-section">
  <h2>Cloud & Infrastructure</h2>
  <p>
    I built and deployed a serverless application on AWS — S3, CloudFront, Lambda, DynamoDB, and API Gateway — provisioned with CloudFormation and deployed automatically through GitHub Actions. The site is live and the source is public on GitHub.

  </p>
